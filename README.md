# 🌤️ Weather Dashboard

A beautiful, animated weather application built with React that provides real-time weather information with stunning visual effects.

## ✨ Features

- 🌡️ **Real-time Weather Data** - Get current weather information for any city worldwide  
- 🎨 **Animated Background** - Beautiful gradient background with shifting colors  
- ☁️ **Floating Clouds** - Realistic cloud animations that drift across the screen  
- 🍃 **Falling Leaves** - Nature-themed leaf animations for organic ambiance  
- ☀️ **Flying Weather Emojis** - Dynamic sun and weather icons that move across the sky  
- 💎 **Glass Morphism Design** - Modern frosted glass UI with backdrop blur effects  
- 📱 **Fully Responsive** - Optimized for desktop, tablet, and mobile devices  
- ⚡ **Smooth Animations** - Hover effects, transitions, and interactive elements  
- 🔒 **Secure API Integration** - Environment variables for API key protection

## 🎯 Getting Started

### Prerequisites

- **Node.js** (v14 or higher) - [Download here](https://nodejs.org/)
- **npm** or **yarn**
- **OpenWeatherMap API key** - [Get it here](https://openweathermap.org/api)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/weather-dashboard.git
   cd weather-dashboard

2. **Install dependencies**

   ```bash
   npm install

3. **Set up environment variables**

    ```env
    REACT_APP_API_KEY=your_openweathermap_api_key_here

4. **Start the development server**

    ```bash
    npm start

5. **Open your browser**
    Navigate to http://localhost:3000 to see the app in action! 🎉

## 🔑 Getting Your API Key

1. Visit [OpenWeatherMap](https://openweathermap.org/)
2. Sign up for a free account
3. Navigate to the **API keys** section
4. Generate your API key
5. Add it to your `.env` file
6. Restart your development server

> ⚠️ **Note:** Keep your API key secure and never commit it to version control!

## 🎨 Design Features

### 🌈 Animations & Effects

- **Gradient Background:** Continuously shifting color gradients (15s cycle)
- **Floating Clouds:** Realistic cloud movements with CSS transforms
- **Falling Leaves:** Nature-themed animations with 360° rotation effects
- **Flying Emojis:** Weather-themed emojis that traverse the screen
- **Glass Effects:** Frosted glass morphism with backdrop filters
- **Sparkle Effects:** Subtle sparkle animations on glass cards
- **Button Shine:** Sliding highlight effects on hover
- **Card Float:** Gentle floating animation for the main card

### 📱 Responsive Design

- **Mobile-first approach** with optimized breakpoints
- **Touch-friendly interface** with larger tap targets
- **Adaptive animations** – reduced complexity on smaller screens
- **Flexible typography** that scales across devices
- **Optimized performance** for mobile browsers
